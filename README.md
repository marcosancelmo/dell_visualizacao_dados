# Dell — Visualização de Dados

Repositório destinado ao armazenamento dos **arquivos, exercícios, atividades e trabalhos desenvolvidos durante o curso de Visualização de Dados da Dell**.

## 📚 Sobre o repositório

Este repositório reúne os materiais produzidos ao longo do curso, servindo como registro dos estudos e atividades práticas realizadas durante a formação.

## 📂 Conteúdo

O repositório pode incluir:

* Exercícios e atividades práticas;
* Trabalhos desenvolvidos durante o curso;
* Arquivos utilizados nas atividades;
* Bases de dados;
* Análises e visualizações;
* Projetos desenvolvidos ao longo da formação;
* Outros materiais relacionados ao curso.

## 🎯 Objetivo

Organizar e documentar os conhecimentos adquiridos durante o curso, mantendo os trabalhos e atividades desenvolvidos em um único local e permitindo acompanhar a evolução dos projetos de **Visualização de Dados**.

## 🛠️ Tecnologias e ferramentas

As ferramentas utilizadas podem variar de acordo com cada atividade ou projeto desenvolvido durante o curso.

Entre elas, podem estar:


* Python
* Seaborn
* Matplotlib
* Outras ferramentas relacionadas à análise e visualização de dados
